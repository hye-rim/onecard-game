# 원카드 🃏

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 원카드 (2~4명). [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- 카드는 52장 + 조커 2장. 2명이면 7장씩, 3~4명이면 5장씩 받는다. 버린 더미 맨 위 카드와 **모양이나 숫자가 같은** 카드를 낸다 (조커는 언제든). 낼 수 없거나 내기 싫으면 한 장 뽑고 차례를 넘긴다
- **공격 카드**: 2 는 2장, A 는 3장(♠A 는 5장), 흑백 조커 5장, 컬러 조커 7장. 공격을 받으면 같은 숫자나 같은 모양의 공격 카드(조커는 언제든)로 막으며 장수가 쌓이고, 막지 못하면 쌓인 장수만큼 뽑는다. 조커는 조커로만 막는다
- **특수 카드**: J 다음 사람 건너뛰기 · Q 방향 바꾸기(2명이면 J 와 같다) · K 두 사람 건너뛰기 · 7 모양 바꾸기(내면서 모양을 고른다)
- **원카드**: 카드를 내고 한 장이 남을 때 미리 ☝️ 원카드! 를 눌러 두지 않았으면 벌칙으로 2장을 뽑는다
- **파산**: 손에 카드가 20장이 되면 그 사람은 빠지고(카드는 더미 밑으로) 남은 사람이 이어 간다. 카드를 모두 내면 이기고, 한 명만 남아도 이긴다
- 컴퓨터: 쉬움은 낼 수 있는 카드를 아무거나(가끔 원카드를 깜빡), 어려움은 ① **J·Q·K 로 연달아 낼 수 있는 줄**(2명일 땐 모두 상대를 건너뛴다)이 긴 카드부터 내서 카드를 빨리 비우고, ② 안 보인 카드(내 손패·버린 더미 밖)로 **상대가 낼 카드가 없을 확률**을 계산해 상대가 막힐 만한 카드를 내며(7 은 상대에게 가장 없을 만한 모양으로 바꾼다), ③ 공격은 안 보인 공격 카드로 **상대가 막을 확률**을 보고 쓰며, 조커는 아껴 둔다. 이 계산은 사람도 볼 수 있는 정보(버린 더미·상대 카드 수)만 쓴다. 예전 어려움은 `hard1` 로 남겨 두어 시험에서 비교한다 (새 어려움이 예전 어려움을 약 57%, 쉬움을 약 66% 이긴다 — 운이 큰 게임이라 차이가 크지 않다). 컴퓨터 1~3명과 할 수 있다 (3·4인은 어려움)
- 컴퓨터를 이긴 횟수는 `onecardWins` (로비 표시용), 온라인 전적은 `onecardOnline`
- **온라인 대전**: 빠른 대전(2명, 바로 시작) · 방 만들기(방장이 2~4명이 모이면 시작, 4글자 방 코드·초대 링크) · 한 번 둘 때마다 30초(넘기면 대신 한 장 뽑고, 연달아 두 번 넘기면 빠짐) · 기권(3~4명이면 나만 빠지고 계속) · 한 판 더(모두 눌러야 시작, 먼저 하는 사람이 돈다) · 끊겨도 30초 안에 돌아오면 이어서. 서버가 같은 규칙(`public/logic.js`)으로 모든 수를 검사하고 **남의 손패는 장수만 보낸다**. 차례가 아니거나 낼 수 없는 카드는 무시한다. 방 코드를 짧은 시간에 많이 틀리면 잠깐 막는다
- M 소리

규칙과 컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리·온라인 연결은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(규칙·컴퓨터·2~4명 전체 대국), `test/server.test.js`(서버를 띄워 2~4명이 한 판을 끝까지 두는 흐름·손패 숨김·시간 초과·기권·재접속 등).
